# SubsTracker 多語言支援 (i18n)

## 概述

SubsTracker 現已支援多語言介面，使用者可以在系統設定中切換顯示語言。

## 支援的語言

- 🇨🇳 **簡體中文 (zh-CN)** - 預設語言
- 🇹🇼 **繁體中文 (zh-TW)**
- 🇬🇧 **English (en)**

## 使用方式

### 切換語言

1. 登入系統後，進入「系統配置」頁面
2. 在「顯示設置」區塊找到「語言 / Language」下拉選單
3. 選擇您想要的語言
4. 系統會自動重新載入並套用新語言

### 自動語言偵測

系統會根據以下優先順序偵測語言：

1. **localStorage** - 使用者上次選擇的語言
2. **瀏覽器語言** - 根據瀏覽器的 `Accept-Language` header
3. **預設語言** - 簡體中文 (zh-CN)

## 技術架構

### 檔案結構

```
src/
├── i18n/
│   ├── locales/
│   │   ├── zh-CN.json      # 簡體中文語言檔
│   │   ├── zh-TW.json      # 繁體中文語言檔
│   │   └── en.json         # 英文語言檔
│   ├── index.js            # i18n 核心模組 (Node.js)
│   ├── i18n-browser.js     # 瀏覽器端 i18n 腳本
│   └── server.js           # 伺服器端 i18n 處理
└── views/
    └── pages.js            # 整合 i18n 到頁面模板
```

### 語言檔格式

語言檔使用 JSON 格式，採用階層式結構：

```json
{
  "common": {
    "appName": "訂閱管理系統",
    "loading": "載入中...",
    ...
  },
  "login": {
    "title": "訂閱管理系統",
    "username": "使用者名稱",
    ...
  },
  ...
}
```

### 翻譯鍵值命名規範

- 使用點號分隔的階層式鍵值：`section.key`
- 通用文字放在 `common` 區塊
- 頁面特定文字使用頁面名稱作為前綴（如 `login`, `dashboard`）
- 使用有意義的英文鍵值名稱

## API 使用

### 瀏覽器端

```javascript
// 取得翻譯文字
const text = window.t('login.title');

// 帶參數的翻譯
const greeting = window.t('common.greeting', { name: '張三' });

// 切換語言
window.i18n.setLocale('zh-TW');

// 取得當前語言
const currentLang = window.i18n.getLocale();

// 取得所有支援的語言
const locales = window.i18n.getSupportedLocales();
// 返回: [{ code: 'zh-CN', name: '简体中文' }, ...]
```

### HTML 屬性

可以使用 `data-i18n` 屬性自動翻譯元素內容：

```html
<!-- 翻譯文字內容 -->
<h1 data-i18n="login.title"></h1>

<!-- 翻譯 placeholder -->
<input type="text" data-i18n="login.username" placeholder="">

<!-- 翻譯 title 屬性 -->
<button data-i18n-title="common.close">X</button>

<!-- 翻譯 aria-label -->
<button data-i18n-aria="nav.toggleMenu">
  <i class="fas fa-bars"></i>
</button>
```

## 新增語言

### 1. 建立語言檔

在 `src/i18n/locales/` 目錄建立新的語言檔，例如 `ja.json`（日文）：

```json
{
  "common": {
    "appName": "サブスクリプション管理システム",
    ...
  },
  ...
}
```

### 2. 更新 server.js

在 `src/i18n/server.js` 中加入新語言：

```javascript
import ja from './locales/ja.json';

const translations = {
  'zh-CN': zhCN,
  'zh-TW': zhTW,
  'en': en,
  'ja': ja  // 加入日文
};

const SUPPORTED_LOCALES = ['zh-CN', 'zh-TW', 'en', 'ja'];
```

### 3. 更新語言選擇器

在 `src/views/configPage.html` 的語言下拉選單加入新選項：

```html
<select id="languageSelect">
  <option value="zh-CN">🇨🇳 简体中文</option>
  <option value="zh-TW">🇹🇼 繁體中文</option>
  <option value="en">🇬🇧 English</option>
  <option value="ja">🇯🇵 日本語</option>
</select>
```

## 本地測試

### 使用 Wrangler Dev 測試

```bash
cd SubsTracker
wrangler dev --remote
```

開啟瀏覽器訪問 `http://localhost:8787`，測試語言切換功能。

### 連接遠端 KV

使用 `--remote` 參數可以連接到 Cloudflare 上的 KV 資料庫，讀取真實的訂閱資料：

```bash
wrangler dev --remote
```

## 注意事項

1. **語言偵測邏輯**：
   - 繁體中文：`zh-TW`, `zh-HK`, `zh-Hant` 等
   - 簡體中文：`zh-CN`, `zh-Hans`, `zh` 等
   - 英文：任何 `en-*` 開頭的語言碼

2. **儲存機制**：
   - 使用者選擇的語言會儲存在瀏覽器 `localStorage`
   - 鍵值：`app_locale`
   - 下次訪問時會自動套用

3. **頁面重新載入**：
   - 切換語言後會自動重新載入頁面
   - 避免手動管理所有 UI 元素的翻譯狀態
